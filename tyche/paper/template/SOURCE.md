# ICLR 2027 style files

These files are copied unchanged from the official ICLR template repository,
<https://github.com/ICLR/Master-Template>, directory `iclr2027/`, at commit
`46ed6f4c6cef5b175dde23639e77d44c3463b230`.

- `iclr2027_conference.sty`, `iclr2027_conference.bst`, `math_commands.tex`
- `fancyhdr.sty`, `natbib.sty` (bundled by the template for self-contained builds)

They remain under the terms set by their authors (see the headers of each
file). Tyche only generates the document body around them.
