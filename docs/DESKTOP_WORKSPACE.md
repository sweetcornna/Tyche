# Tyche Desktop 工作台

此版按本机 Codex Desktop 26.901.51231 的静态界面规范重新实现 Tyche 的对话工作台。参考来自已安装应用的样式常量和组件结构：275px 默认侧栏、22px 输入框圆角、150ms 控件反馈、300ms 面板过渡、灰阶浅深主题。界面组件由本项目自行实现，未复制应用源码、商标资产或用户数据。

本机 Desktop 的实时窗口受到 Computer 工具访问限制，因此没有把该窗口的交互检查称为像素级复刻验收。实际验收在 Tyche 控制平面提供的生产构建上完成。

## 已实现的操作

- 对话侧栏：新建、切换、重命名、置顶、归档、恢复；文本草稿随对话切换保留。
- 搜索与命令面板：按标题和正文查找历史，方向键选择、Enter 跳转、Escape 关闭。
- 消息区：Markdown、表格、代码块复制、消息复制、引用、编辑后重发、重新生成、跳到最新消息。编辑和重生成追加新回合，保留原消息。
- 输入框：自动增高、Enter 发送、Shift Enter 换行、中文输入法保护、文本文件附件、模型与推理强度选择。
- 请求状态：真实连接／生成／校验阶段与耗时、停止、失败重试。停止信号传至 SDK；服务端拒绝取消后的迟到结果和先于请求到达的取消竞态。
- 设置：常规、连接、模型池与六角色分配、Paper 状态、快捷键。主题直接切换，不需要模型请求。
- 工具面板：工作流节点联动、执行状态、事件记录、Paper 持仓与 3D；支持展开、收起和键盘／拖动调宽。
- 动效：按钮反馈、菜单和消息入场、搜索／设置开合、侧栏和详情过渡；界面动效开关同时停用活动 3D。尊重系统减少动态效果偏好。

原生 Codex 的终端、Git 工作树、应用连接器、文件编辑执行环境需要宿主支持，Tyche 未添加这些能力的空壳入口。对话回复仍先经过现有结构化结果与凭据校验，再显示完整正文；生成阶段不伪造逐字输出。

## 本地历史和安全

完整启动命令 `node scripts/tyche-control-plane.mjs --port 8788` 将对话保存在固定、Git 忽略的 `data/control/conversations.json`，文件权限为 0600。最多 100 个对话、每个 100 条消息、总计 2 MiB。新的鉴权会话恢复最近未归档对话；模型上下文最多使用当前对话最后 8 条。API Key 仍只存在服务端会话内存，不写入历史、浏览器存储或仓库。

历史接口采用现有会话和 CSRF 检查、专用 DTO、字段白名单，拒绝任意路径、查询参数和账户选择。写入使用锁和原子替换，符号链接、权限过宽、损坏文件和版本冲突均报错。历史保存失败单独显示“重试保存”，不把已经生效的设置误报为回滚，不重新调用模型。

对话历史可跨登录恢复；连接凭据、策略配置和未发送的输入草稿仍按原有会话／页面生命周期管理。归档保留历史，不等同删除。

## 连续交互打磨

- 生成期间输入框保持可编辑；点击发送可排队最多三条消息，每条明确绑定当前对话。上一条成功后按顺序接续；停止、失败、会话失效或历史未保存时暂停，需手动继续。后台不启动下一条，回到前台后检查状态。仅在页面内保存队列，刷新不重播。
- 文本和附件作为同一份草稿随对话切换保留；迟到的回复不会清空下一条草稿。退出清空页面草稿并使未结束的文件读取失效。会话自然失效保留页面草稿和暂停的队列。
- 按完整序列化消息长度校验 8000 字符，包括附件文件名和分隔符；Enter 与点击发送共用校验。读取附件时暂缓提交。
- 历史分为置顶、今天、最近 7 天和更早；操作菜单贴近行显示，支持方向键和 Escape，避免被滚动区域截断。
- 搜索区分加载、错误、无结果，只显示对应当前关键词的结果；支持中文输入法确认。
- 重命名等待服务端成功才关闭，失败保留内容并就地显示。设置保存错误显示在当前弹窗中。
- 窄屏侧栏和详情提供遮罩、焦点循环与 Escape，关闭后返回触发区域；主界面隐藏于辅助技术的交互范围。跳到最新消息按钮跟随消息区域，输入框增高后不会错位。
- 运行结果收为紧凑状态条，点击查看完整结果及错误。界面继续保持灰阶，不增加说明性小字。
