# 工作台视觉验收

本轮使用 OpenDesign 的 `redesign-existing-projects` 生成原型，再迁移至现有 React 工作台。
采用分层深灰表面、矿物绿强调色、斜向构图和错位叠片。功能、数据、错误信息保留，未恢复宣传或帮助段落。
原型与设计规范位于 `docs/opendesign`，不参与生产运行。

全部交易截图使用隔离内存夹具，不包含实际账户或外部网关数据。

- `login.jpg`：正式控制平面的登录主视觉。
- `workspace.jpg`：聊天空态与真实工作流进度区域。
- `positions.jpg`：BTC 多仓、ETH 空仓和完整核算时间。
- `light-workspace.jpg`：浅色主题与聊天后的紧凑场景。
- `mobile-workspace.jpg`、`mobile-positions.jpg`：390 CSS 像素宽度的实际构建，截图文件的捕获分辨率可能小于 CSS 尺寸。
- `blender-source.png`：Blender 中打开新模型并播放、暂停关键帧后的截图。

本轮验证：

- `npm run check`、生产构建、前端 28 项测试、`git diff --check` 通过。
- 全套 413 项测试串行通过。默认并行执行时，原有 worker 崩溃测试的 200 毫秒超时在系统负载下触发；该项单独复跑通过，未修改业务测试或超时策略。
- 构建使用实际控制平面的同源静态服务；未用 Vite 开发服务替代。
- 桌面和 390 CSS 像素宽度下检查工作台与持仓详情；窄屏根元素 `clientWidth = scrollWidth = 390`。
- 本轮浏览器 viewport 覆盖未生效，窄屏改为在隔离服务中，以固定 390 × 844 iframe 的 srcdoc 加载原始构建入口；生产 CSP 和认证配置不变。该临时验收页面不交付。
- 窄屏最多一个 WebGL 画布；键盘暂停后画布为零，海报与全部持仓数据可用。
- 原生对话框 Escape 关闭，焦点返回展开入口；角色导航和设置入口可用。
- 使用隔离网关验证连接字段、主题切换与紧凑场景；会话到期返回登录，不残留持仓。
- Blender 中查看新的叠片、轨道和节点，播放关键帧确认动作。旧窗口未保存状态先另存到临时副本，未覆盖新源文件。
- GLB 为 176,404 字节、2,204 三角面；全部材质使用 KHR_materials_unlit，含 Idle/Reveal，无外部纹理。

此前已经完成并仍由单元/接口测试覆盖：挂单、部分成交和撤单、减仓/平仓/强平、无仓位、缺少估值、数据错误、事件去重与断档、鉴权与凭据过滤、符号链接和资源 MIME。
减少动态效果仍走同一海报降级分支，本轮未改动操作系统偏好或浏览器 GPU 设置。
Three.js 的独立延迟加载块约 165 KiB gzip；Vite 仍提示其未压缩大小超过 500 kB。
